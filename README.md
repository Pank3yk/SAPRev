# SAP Master Quiz Reviewer

A responsive SAP multiple-choice reviewer built with HTML, CSS, Bootstrap 5, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. Bootstrap is loaded from jsDelivr, so an internet connection is needed for Bootstrap styling.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

## Notes
- Contains 128 questions across SD, MM, PP, FI, CO/S/4HANA, and HCM.
- Two process-diagram questions (SD Q24 and MM Q24) refer to pictures that were not included in the text supplied. They are included but have no answer key until the images / correct picture are provided.
- A small number of answer keys are marked for instructor/course-material verification in the question data.
- The score percentage excludes questions without confirmed answer keys.
